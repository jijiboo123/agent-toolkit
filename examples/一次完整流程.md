# 示例：一次"看得见"的修改

假设要把 `app.js` 里的 `renderHero` 加一行动态标题。

## 1. 先跳转，让人看到落点

```bash
python scripts/jump.py "app.js:911"
```

VS Code 光标停在 911 行。

## 2. 说清要改什么

> 在第 911 行 `els.condition.textContent = ...` 下面插入 3 行，更新浏览器标签页标题。

## 3. 改（这里改动只有 3 行，用逐字）

```bash
python scripts/type_write.py app.js --from-file patch.txt --no-clear --delay 0.03
```

## 4. 再跳转，看结果

```bash
python scripts/jump.py "app.js:912"
```

## 5. 语法检查

```bash
node --check app.js
```

## 6. 功能验证

```bash
python scripts/jump.py "asserts.cjs:1"
node scripts/jsdom_harness.cjs --dir . --html index.html --js app.js \
     --origin http://127.0.0.1:8765/ --wait "#content" --assert asserts.cjs
```

输出：

```json
{ "waitOk": true, "ok": true, "result": { "title": "13°C 北京 · 天气预报" }, "errors": [] }
```

## 7. 贴结果

> 改完实测：标题变成 `13°C 北京 · 天气预报`，断言通过，0 运行时错误。
