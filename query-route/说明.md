# 查询路线

查火车（含中转换乘），把结果拼成一条完整行程，自动算换乘缓冲。

**一个窗口办完所有事**：填起终点 → 查询 → 双击车次 → 行程自动生成。

## 运行

双击 **`启动.bat`**（用系统 Python 3.13）。

或命令行：`python query_route.py`

## 界面就三块

```
┌ 起点 [武汉]  终点 [上海]  日期 [2026-11-05]           [查询] [导入车次]
│ 状态：直达 53 趟 ｜ 要看中转方案，切到「中转」标签点「查找中转方案」
├────────────────────────────────────────────────────
│ [直达（53）] [中转（12）]        ← 两个标签页
│  车次   出发站   到达站   出发  到达  历时  二等座
├────────────────────────────────────────────────────
│ 已选行程（双击上方车次自动加进来）
│  [删除选中][上移][下移][清空行程][复制路线][保存][载入]
│ 状态：共 1 段 · 全程 3小时36分 · 总票价 ￥354 · ✓ 换乘时间充裕
└────────────────────────────────────────────────────
```

## 直达和中转怎么用

**直达**：点「查询」只查直达（**1 次接口调用**），结果列在「直达」标签。双击某趟 → 加入行程。

**中转**：切到「中转」标签 → 点 **「查找中转方案」** 才查（会先问你要不要花额度）。

- 中转站留空 → 自动试 `郑州东 / 武汉 / 南京南`（跳过起终点本身；某个枢纽查不到第一程就自动早退，不浪费调用）
- 想指定 → 填中转站（多个用逗号隔开），只查你填的

> **为什么改成按钮触发**：以前点一次「查询」就顺带算中转，固定烧 7 次额度。
> 现在不查中转只花 1 次；查了也就 3~6 次，而且反复查同一线路**全部命中缓存，0 消耗**。

配对规则（不让你白跑一趟）：

| 规则 | 说明 |
|---|---|
| 同站换乘 | 第一程到达站必须**等于**第二程出发站，不跨站 |
| 换乘时间 ≥ 30 分钟 | 太短赶不上 |
| 换乘时间 ≤ 6 小时 | 等太久不如换走法 |
| 按总耗时排序 | 最快的排最前 |

双击「中转」里的一行 → **一次加入两段**，行程里自动出现换乘关系与缓冲提示。

## 换乘缓冲怎么判断

| 情况 | 建议最少 | 低于会标红 |
|---|---|---|
| 同一车站 | 15 分钟 | 站内通道也要时间 |
| 不同车站 | 60 分钟 | 要坐地铁/打车过去 |
| 换乘飞机 | 120 分钟 | 值机+安检 |

到达时间晚于下一段出发，判为**时间冲突**。
跨零点会自动识别（23:30 到达 → 次日 00:30 出发 = 60 分钟）。

## 数据从哪来

| 来源 | 说明 |
|---|---|
| **聚合数据**（主） | 火车票接口；**只支持 15 天内**，**每秒 1 次**（程序已自动限流） |
| **本地缓存**（自动） | 同一线路同一天，**6 小时内不重复请求**；额度用完时自动降级用旧缓存，仍能出结果 |
| **本地车次库**（备） | 点「导入车次」，把 12306 复制的文本粘贴解析入库；API 不可用时自动查这里 |

## 免费优先（默认开启）

顶部有个「**免费优先**」勾选框，默认打开。数据来源顺序：

```
本地库有这条线路 → 直接返回（0 消耗，状态栏标「本地库 N 趟（免费，0 消耗）」）
        ↓ 没有
接口查询（1 次额度）→ 结果自动入本地库
        ↓ 失败
本地库兜底
```

- **勾着**：查过的线路永远免费，离线也能用
- **取消勾选**：强制走接口拿最新数据（比如怀疑车次调图了）

状态栏会明确告诉你这次花没花额度：

| 状态栏显示 | 含义 |
|---|---|
| `接口 1 次（花了额度）` | 走了网络 |
| `本地库 53 趟（免费，0 消耗）` | 完全没联网 |
| `接口 2 次 + 本地库 12 趟` | 中转查询里部分走了本地 |

**省额度的四个机制**：
1. 查询只查直达（1 次），中转按需点按钮（省 6 次）
2. 6 小时缓存：同一线路反复查 → 0 次调用
3. **查询结果自动沉淀进本地库**（`车次库.json`）→ 以后这条线路不联网也能查
4. 额度耗尽时用旧缓存兜底，不让你看到"查询失败"

> **入库是可见的**：每次查询后状态栏会显示「已入库 新增 x / 更新 y」。
> 同样数据再查一次会显示「新增 0 / 更新 2」，说明去重生效、没有重复堆积。

> 用得越久越省：查过的线路全部进了本地库，站名也自动累积成下拉提示。


## 按钮说明

| 按钮 | 作用 |
|---|---|
| 查询 | 查直达（勾选了就连中转一起算） |
| 导入车次 | 粘贴 12306 结果存进本地库（支持一键「从剪贴板粘贴」），作为备用数据 |
| 复制路线 | 整条行程文本进剪贴板 |
| 保存 / 载入 | 存成 JSON，下次接着改 |

## 已知限制

1. **只支持一次中转**（两段）。多段中转在高铁网络里收益很小，查询次数还会翻倍。
2. **中转方案只认同站换乘**，不支持「到站后打车去另一个站」。
3. **聚合数据免费额度有限**（当日用完返回 `10012`），此时会自动退回本地车次库。
4. **只能查 15 天内**的日期，更远会返回 `281701`。
