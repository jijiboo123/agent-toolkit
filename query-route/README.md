# 查询路线 Query Route

一个查火车票、**自动算中转换乘**、并把结果拼成完整行程的桌面小工具（Python + tkinter，单窗口）。

不是又一个查票网页——它解决的是查完之后的事：**这段接得上吗？换乘留的时间够吗？**

## 它做什么

| 功能 | 说明 |
|---|---|
| **直达查询** | 输入起终点和日期，列出所有车次（车次、站点、时刻、历时、二等座票价） |
| **中转换乘** | 自动试若干枢纽站，把「A→枢纽」和「枢纽→B」配对成中转方案，按总耗时排序 |
| **换乘校验** | 同站换乘要 ≥15 分钟、异站 ≥60 分钟、换机 ≥120 分钟，不够就标红 |
| **行程拼装** | 双击车次加入行程，自动算全程耗时、总票价、风险点，可复制/保存/载入 |
| **免费优先** | 查过的线路走本地库，**0 次接口调用**；没查过的才联网 |
| **数据沉淀** | 每次查询结果自动入库，越用越省额度 |

## 快速开始

### 1. 申请接口 key（可选，没有也能用本地库）

去 [聚合数据](https://www.juhe.cn/docs/api/id/817) 申请「火车订票班次查询」，免费额度够个人用。

### 2. 配置

```bash
cp api_config.example.json api_config.json
# 编辑 api_config.json，把 "key": "" 填成你自己的 AppKey
```

> 不配置也能跑：程序会自动降级到本地车次库（用「导入车次」把 12306 页面复制的文本粘进来）。

### 3. 运行

```bash
python query_route.py
```

Windows 上直接双击 `启动.bat`。

依赖：**只有 Python 标准库 + tkinter**，不需要 pip install 任何东西。

## 中转换乘怎么算的

这是整个项目里最有意思的部分（`planner.py`）：

```python
# 只有「上一段到达站 == 下一段出发站」才组合，不让你跨站换乘
for first in first_legs:
    for second in by_station.get(first["to_station"], []):
        gap = depart_minutes - arrive_minutes
        if gap < 0:
            gap += 24 * 60              # 跨零点
        if not (30 <= gap <= 360):      # 少于 30 分赶不上，多于 6 小时不如换走法
            continue
        plans.append({...})
```

用 `by_station` 建索引而不是双层嵌套遍历，1 个枢纽 400 趟车时差别很明显。

枢纽默认试 `郑州东 / 武汉 / 南京南`，也可以自己填（多个用逗号分隔）。

## 省额度的四个机制

| 机制 | 效果 |
|---|---|
| 查询只查直达，中转按需点按钮 | 每次查询从 7 次调用降到 1 次 |
| 6 小时缓存 | 同一线路反复查 → 0 次 |
| 结果自动沉淀进本地库 | 查过的线路永久离线可查 |
| 额度用完时用旧缓存兜底 | 不会让你看到"查询失败" |

状态栏会明确告诉你这次花没花额度：`接口 1 次（花了额度）` 或 `本地库 53 趟（免费，0 消耗）`。

## 几个技术细节

- **字段映射写在配置里**：`records_path` + `field_map` 用点号路径取嵌套字段，换供应商只改 JSON 不改代码。
- **票价按坐席名取**：接口的 `prices` 是数组，第一个是商务座（1145 元）。按 `seat_name == "二等座"` 取才是 371 元。
- **接口限流**：聚合数据每秒 1 次，代码里做了 1.2 秒的节流，连点也不会报 10015。
- **跨零点**：23:30 到达 → 次日 00:30 出发，按 60 分钟算，不会算成 1440 分钟。

## 已知限制

1. **只支持一次中转**（两段）。多段中转在高铁路网里收益很小，查询次数还会翻倍。
2. **只认同站换乘**，不支持「到站后打车去另一个站」。
3. 聚合数据**只能查 15 天内**，更远的日期会返回 `281701`。
4. 免费优先意味着可能用到旧数据，怀疑调图时取消勾选强制刷新。

## 关于数据来源

用的是聚合数据的**正版商业接口**，不爬 12306（它没有公开 API，裸调查询接口直接 302 弹回，批量抓取也违反其用户协议）。
